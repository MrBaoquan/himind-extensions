# 媒体资源库

`com.himind.media-library` 是 HiMind Agent 的媒体发现、采纳与共享资源库插件。

## 主要能力

- 在线检索：Pexels 图片/视频、Unsplash 图片、Freesound 音频
- 本机文件夹：注册目录、分批扫描、增量刷新、候选索引
- 资源库：用户主动采纳在线或本地素材，不会把搜索结果自动加入
- 本地/SMB：同一套 Library 抽象支持本地目录和 SMB UNC 目录
- 快速检索：SQLite + FTS5 本机索引
- 预览：图片、视频、音频统一预览入口
- 来源记录：作者、许可证、原始链接、SHA-256 和采纳人
- 多人共建：SMB 资源库使用每用户追加式 JSONL 元数据

## 界面结构

- 主界面只保留搜索、范围/类型筛选和结果，不展示资源库、文件夹或凭据配置。
- 资源库、本机文件夹、在线来源和索引状态统一收进“媒体库设置”弹窗。
- 音频卡片可直接播放/暂停并显示进度；点击卡片其他区域仍进入详情。
- 搜索、设置和刷新使用带 tooltip 与可访问名称的 SVG 图标按钮；非编辑区域禁用网页右键菜单。
- 默认入库资源库只在设置中选择；素材详情可以为单次采纳切换目标资源库。
- 资源库可以改名、切换访问模式或从 HiMind 移除；本机来源可以改名或移除索引，两者都不会删除磁盘文件。
- 在线筛选使用搜索区下方的内联折叠面板，不再以浮层遮挡结果。
- 音频卡片播放态使用独立 pause SVG，暂停后恢复 play SVG。
- 点击素材卡片打开右侧预览面板；详情支持上一项/下一项和键盘左右切换。
- 设置和预览均支持 Esc 关闭、背景滚动锁定和焦点返回。
- 未保存修改、移除资源库或本机来源等确认操作使用应用内 `alertdialog`，不调用浏览器原生确认框；取消、遮罩关闭、焦点陷阱和焦点返回均已覆盖。

## 入库元数据与快速检索

- 入库前可以修改素材名称；物理文件名会保留源文件扩展名。
- 可以填写分类路径和标签。分类路径是逻辑分类，不改变 `assets/<sha-prefix>/` 的内容寻址存储结构。
- 标签、分类路径和标题会写入 SQLite FTS 索引；已采纳资源还会把标签和分类路径写入 SMB 用户目录的 catalog JSONL。
- 搜索支持名称、文件名、路径、许可证、标签和分类路径的关键词匹配，并继续支持图片/视频/音频类型与来源范围筛选。
- SHA-256 去重优先于重复复制；同一素材再次入库时保留已有名称和元数据。

## 大数据量检索

- SQLite search_fts_v2 分列索引标题、文件名、路径、标签、分类路径、许可证和作者。
- 查询使用 BM25 字段权重、类型/范围/资源库前置过滤和稳定游标分页。
- 宽泛查询先处理最近 1000 条匹配窗口；窗口不足时回退全局 FTS 排名。
- 1–2 字中文查询使用受限索引扫描兜底，避免无界全表扫描。
- 组合索引覆盖最近资源、类型和资源库范围，旧数据库首次打开会自动回填 FTS v2。
- 公开基准：10 万条常见关键词 P95 约 84ms、组合筛选约 21ms、最近资源约 5ms。

## 凭据管理

在线来源凭据不保存在插件目录。插件在 `plugin.json` 中声明：

- `pexels.api`
- `unsplash.api`
- `freesound.api`

用户在 HiMind Agent 的「账号与凭据」中配置。插件进程通过
`HIMIND_CREDENTIAL_BROKER_URL` 和一次性 token 按能力调用获取凭据。

旧版 `provider-keys.json` 和 `media-library.provider.configure` 已移除。
升级到 2.0.0 后需要重新在 Agent 凭据中心录入密钥。

## 资源库结构

本地资源库或 SMB 共享库的根目录结构：

```text
library/
├─ assets/
└─ .himind-media/
   ├─ library.json
   └─ catalog/
      └─ users/
         └─ <actor>.jsonl
```

- `assets/` 保存资源文件
- `library.json` 使用 `library_id` 识别同一共享库
- `catalog/users/*.jsonl` 每个用户只写自己的事件文件，避免多人同时写同一文件
- 插件索引数据库位于 Agent 的插件私有数据目录，不放在 SMB 上

SMB 资源库必须使用 UNC 路径，例如：

```text
\\nas\media\team-library
```

本地资源库支持：

- `copy`：复制到资源库 `assets/`
- `reference`：只登记原文件路径

SMB 共享库只支持复制，避免把某台电脑的本地路径写入共享目录。

## 工作流

```text
在线搜索 / 添加本机文件夹
        ↓
候选索引与预览
        ↓
用户选择目标资源库并点击“添加到资源库”
        ↓
复制/上传、SHA-256 去重、写入来源与许可证
        ↓
资源库条目、标签和检索索引
```

## 安全与限制

- 在线素材进入 SMB 共享库时，必须明确确认允许再分发
- 未知或许可证不明确的资源默认不能进入 SMB 共享库
- 预览接口只允许读取已索引候选或已采纳资源
- SMB 认证优先使用 Windows 集成身份；多 SMB 账号 Profile 属于后续 Agent 能力
- 当前插件目标平台为 Windows x64
- 本期不使用语义向量索引；先提供文件名、标题、标签和路径的 FTS/包含检索
- SMB 实时文件监听不在本期范围，使用打开页面时刷新或手动分批扫描
