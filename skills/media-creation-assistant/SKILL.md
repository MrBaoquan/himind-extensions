# 媒体创作助手

生图本身不难，难的是**同一批素材看起来像一套、事后还能重做出同一套**。本技能把这些判断写成步骤，交给 `media.studio.*` 能力执行。

## 触发边界

适用：

- 需要一批风格一致的素材（展项主视觉、图标、电商主图、封面套图）。
- 已有素材要改：换背景、换风格、扩尺寸、补一版构图。
- 要追问「这张图当时是怎么生成的」，或要沿用上次的配方。
- 在媒体资源库里对某张图片点「AI 处理」。

不适用：

- 剪辑、转码、抽帧、拼缩略图：用「媒体处理工具」。
- 视频生成与配音：由内核的生视频与语音能力承担，本技能不负责编排。
- 只做检索、采纳与资源库管理：用「媒体资源库」。
- 只是要一张图、且不需要复现：直接用内核生图能力就够了，不必套矩阵。

## 第一原则

1. **先配方，后数量**：没定风格就批量跑，得到的是 20 张互不相干的图。
2. **先小样，后矩阵**：第一次用某组合，先 `1 风格 × 1 尺寸 × 1 张` 确认方向，再放大。
3. **风格交给风格包，提示词只写主体**：把「电影感、留白、克制」写进 `prompt_suffix`，同一位用户第二次使用时才不会漂。
4. **成本有闸门**：矩阵总量 ≤ 36 张；不确定方向时用 2 张变体比较，不要靠堆数量碰运气。
5. **产物必须可追溯**：走媒体创作工具的生成才有血缘；直接调内核生图不会记录配方。
6. **失败按格看**：某个单元格失败不代表整批失败，先读该格的 error 再决定重跑范围。

## 标准流程

```text
1. 读风格包      media.studio.style.list
2. 定需求        主体 + 场景 + 用途（一句中文，不超过 100 字）
3. 小样          1×1×1 或 1×1×2
4. 放大          矩阵 ≤ 36 张，确认后再跑
5. 查进度        media.studio.batch.status
6. 留证据        产物路径 + media_id + 血缘
7. 采纳          需要进资源库时交给媒体资源库的采纳能力
```

第 3 步之后必须停下来看一眼。跳过小样直接跑 36 张，是这类任务里最贵的一种「省事」。

## 风格包怎么选

内置 6 个起步配方，选不到再自定义：

| ID | 适用 |
| --- | --- |
| `clean-product` | 白底/浅底棚拍质感，电商主图与物料封面 |
| `exhibit-keyvisual` | 展项开场视觉，需要纵深与标题留白 |
| `icon-tile` | 方形图标瓦片，深色底、单一符号、无文字 |
| `night-city` | 夜景与灯光氛围，背景板与转场 |
| `ink-poster` | 水墨大留白，文化类展项与封面 |
| `brand-minimal` | 几何纯色，方便叠加标题与 logo |

自定义时：

- `id` 用小写字母、数字、连字符，与内置同名即覆盖它的效果；
- `prompt_suffix` 写**可观察的视觉特征**（光线、构图、材质、留白），不写抽象赞美；
- `avoid` 写真实出现过的问题（文字、水印、人群特写），别写「不要不好看」；
- 覆盖前先用一次小样验证，确认比内置好再保存。

## 矩阵参数

- `styles`：2–3 个足够横向比较；超过 4 个通常是因为需求还没想清楚。
- `sizes`：只选真正会用的尺寸；多平台各一套时再一起跑。
- `variants`：同风格要挑构图差异时用 2–4；只是备份用 2。
- `filename_prefix`：写项目或展项名，产物文件名会自动带上风格与尺寸。

矩阵总量超过 36 张时，先拆成两批；不要为了凑一次跑完去删风格。

## 改图（含媒体资源库入口）

`media.studio.image.rework` 对已有图片改图：

- 输入可以是工作区内路径、`media:<id>`，或资源库里的路径；
- 工作区外的素材会先复制到 `.himind/media/studio-inputs/` 再改，避免被「参考图必须在工作区内」拦住；
- `prompt` 与 `style_id` 至少给一个：只给风格包等于「按这个风格重做一版」；
- 结果保留 `parent_media_id`，多轮修改可以一路回溯。

改图失败最常见的两个原因：参考图不是 PNG/JPEG/WEBP/GIF，或模型只支持改图适配器而服务没绑 `image.edit`。

## 恢复与排查

| 症状 | 先看什么 | 处理 |
| --- | --- | --- |
| `当前会话没有能力代理` | 是否在 Agent 里调用 | 在 Agent 的扩展视图或对话里跑，不要脱离宿主 |
| `本机没有已绑定生图能力的 AI 服务` | `media.studio.runtime.status` 的 providers | 在 AI 服务里绑定 `image.generate` |
| 全部单元格失败 | 该格 error 一致性 | 通常是服务不可用或账号额度问题 |
| 状态 `interrupted` | 作业 JSON | Agent 重启打断；已完成产物仍在，重跑缺的部分 |
| 风格包没生效 | 最终 prompt | `style.list` 里的 `prompt_suffix` 是否为空；空包等于没选 |
| 资源库里没有 AI 处理入口 | 插件是否安装 | 装「媒体创作工具」后重开素材详情 |

## 交付自检

- 需求是一句话，不是一串形容词；风格只来自风格包。
- 先跑过小样，且小样被确认过。
- 矩阵总量 ≤ 36 张，风格数 ≤ 4。
- 每张产物都有 media_id 与血缘，能回答「怎么生成的」。
- 需要入库的素材已采纳，并带项目可检索的标签或分类路径。
- 失败项有明确结论（重跑、换配方或放弃），没有留在「再看看」。
