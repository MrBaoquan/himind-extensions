# 图片交付预检

在修改图片前执行只读准备检查。不得在预检阶段压缩、缩放、覆盖、移动或删除源图片。

## 输入

- 图片源目录或待处理文件范围。
- 预期输出格式、尺寸、质量和目标目录。
- 交付渠道、文件大小、命名、色彩空间、透明度等约束。

缺少必要输入时先列出缺口，不猜测路径、格式或交付标准。

## 工作流

1. 通过 `system.health` 检查 Agent 状态和可用 Capability；失败时返回健康检查错误，不继续假设环境可用。
2. 确认 `com.himind.image-optimizer` 已安装、已启用且版本不低于 `1.0.0`。
3. 只读检查用户指定的图片范围、输出要求和交付约束；不要扫描无关目录或读取凭据文件。
4. 区分已通过检查、阻塞项、风险提示和仍需用户确认的写入动作。
5. 返回下一步建议。实际图片优化必须由受控插件 Capability 执行，并在覆盖或批量写入前获得明确确认。

## 输出

使用中文返回简洁报告：

- `结论`：就绪、部分就绪或阻塞。
- `已通过`：Agent、插件、输入和约束检查。
- `阻塞项`：缺失依赖、无效路径、未声明格式或冲突约束。
- `下一步`：可以安全执行的动作，以及执行前仍需的确认。

## 禁止事项

- 不得在预检阶段修改源图片或生成交付文件。
- 不得绕过 Capability Gateway、插件权限或用户确认。
- 不得输出 Token、Cookie、私钥、凭据或未脱敏的内部地址。
- 不得把“插件已声明”当作“插件运行正常”；必须依据实际检查结果。
