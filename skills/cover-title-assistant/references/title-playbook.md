# 封面标题编创手册

## 目标

生成观众一眼能看懂、愿意点开、且内容经得起核对的主副标题。传播潜力来自信息增量、反差、利益和情绪，不来自夸张词。

## 六组结构

- A 事实/数据型：最硬、最稳。
- B 事实/数据型：更短、更适合新闻。
- C 反差/悬念型：打破预期，但事实必须成立。
- D 反差/悬念型：适合城市、人物、产业变化。
- E 利益/提醒型：对观众有什么直接影响。
- F 人物/情绪型：落到具体人和境遇。

## 主副标题关系

主标题负责钩子，补充信息负责落点；不能把同一句拆成两行冒充两个层级。

- 推荐：`中国汽车第一省` / `安徽，凭什么？`
- 推荐：`乡土中国的时代已经结束了` / `地里的土越来越高，村里的人越来越少`
- 不推荐：`安徽启动小麦收购` / `安徽开始收购小麦了`

## 手机阅读

- 主标题建议 8–16 字。
- 补充信息建议 10–20 字。
- 一页最多一个核心数字。
- 断行优先落在逗号、转折或判断词前后。
- 避免连续两行长句。
