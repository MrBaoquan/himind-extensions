# 实时资源与渲染

## 输入与边界

输入艺术方向或参考画面、目标硬件/分辨率、引擎与管线、帧时/内存/包体预算、资源来源和许可。区分视觉目标与已测性能。海报、视频等离线内容生产不等于实时资源验收，下载或生成成功也不代表可导入可发布。

## 方法

1. 固定渲染基线：版本、管线、色彩空间、曝光、相机、光照、后处理、质量档及代表性场景。选正常和最重视角，保留基准截图与性能采样条件。
2. 逐类定义资源规格：模型单位/坐标/轴心/拓扑/LOD，贴图尺寸/通道/色彩空间/压缩，骨骼/帧率/根运动，粒子峰值、透明层数、材质与 Shader 变体。数值按目标预算分配，不能照抄桌面参数给移动机。
3. 核对导入后尺寸、法线/切线、UV、动画绑定和贴图解释，保留源文件到引擎资源的映射及重建步骤。禁止只改导出结果而丢掉可编辑来源。
4. 用帧分析区分 CPU 提交、GPU 着色/带宽、过度绘制、资源上传和内存问题；先找瓶颈再优化。对透明、阴影、实时光、粒子与纹理分别测量，不能只靠 draw call 总数断言快慢。
5. 在同条件目标构建做前后比较，一次优先改变一种主要成本；截图看轮廓、材质、色偏、文字与交互可读性，采样看帧时、峰值内存、加载和包体。
6. 为低档硬件设计降级层级及缺资源/不支持 Shader 的替代，验证最差视角和输入反馈仍清楚。引擎专项沿用该项目管线，UNIHper 不是资源方法的必需条件。

## 输出与验收

交付资源规范/清单、来源与许可、导入和重建步骤、基准/结果画面、预算实测及降级表。通过条件：引用无丢失、无错误材质、尺度和动画正确；约定视角视觉目标通过，目标构建帧时/内存等未超预算。没有目标机测量则性能未验证；资源未确认许可则不能标可发布。

## 受阻与恢复

缺源文件或管线信息时隔离样本验证，不批量改全库。画面回归恢复该项资源/材质和导入参数，固定相机重测；优化收益不成立就撤销该优化，保留分析数据。共享资产、场景和导入设置按文件所有权串行整合。
