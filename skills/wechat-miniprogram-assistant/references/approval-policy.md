# 安全与审批

| 操作 | 风险 | 要求 |
|---|---|---|
| 状态、项目列表、console/network、截图 | R1 | 直接执行 |
| 开窗、编译、刷新、元素点击/输入、页面导航 | R2 | 遵循用户意图 |
| 构建 npm、生成自动化脚本 | R2 | 说明会写本地产物 |
| 上传体验版、云函数部署、云数据库/存储写入 | R3 | 审批 |
| 删除项目、清缓存、mock wx API、任意 JS 执行 | R3 | 审批 |
| 安装/更新开发者工具、修改 PATH | R3/R4 | 独立安装器流程 |

## 硬规则

- 只调用已注册能力，不编造工具名或参数。
- 项目路径必须在 `workspace_root` 内。
- 不读取或记录 token、ticket、私钥内容；只在安全存储或凭据句柄中使用。
- `import_minicode` 导入后先审查代码，再打开窗口。
- `project.config.json` 的 `scripts.beforeCompile/beforePreview/beforeUpload` 可能执行本地命令，构建前先展示并确认。
- 用户拒绝或审批超时后，不重试破坏性操作。
- 不写微信开发者工具安装目录，不执行任意 shell。
